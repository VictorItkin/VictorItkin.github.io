Расписание работы лаборатории

В лабораторию поступают заявки на испытание. Заявка представляет собой набор анализов, связанных с определенным объектом контроля и точкой контроля. Каждый анализ содержит информацию по лаборантам, допущенным к проведению данного анализа в рамках методики, оборудованию, необходимому для анализа, и времени измерения.

Заявки имеют различные приоритеты выполнения, в частности, плановые заявки должны начинать выполняться точно в заданное время (время начала выполнения первого анализа задано точно; время выполнения остальных не задается, но должно быть минимальным). Разные заявки «по требованию» могут выполняться в произвольном порядке, но более приоритетные следует выполнять быстрее, если это возможно. Для некоторых анализов в рамках заявки может быть задана четкая последовательность выполнения.

Время выполнения анализа делится на неразрывные этапы. Для каждого этапа задаются списки лаборантов и единиц оборудования. При выполнении этапа анализа лаборант и оборудование должны быть заняты одновременно. Любой список (или оба сразу) может быть пустым, что означает, что для данного этапа участие лаборанта и/или использование оборудования не нужно.

Необходимо распределить анализы по исполнителям (лаборантам) с учетом их допуска, а также составить расписание выполнения анализов с учетом графика работы исполнителей. При составлении расписания следует также учесть доступность оборудования.

Для решения разработан эвристический алгоритм с использованием метода случайного поиска (Монте-Карло).

Приведём пример оптимального расписания лаборатории, состоящей из 3-х сотрудников и 2-х единиц оборудования. Лаборатория получила 2 заявки: в первой 5 анализов, во второй - 2. Все анализы состоят из 3-х этапов.
