Неопределённости выбросов парниковых газов

Согласно Руководящим принципам национальных инвентаризаций парниковых газов МГЭИК объём выбросов парниковых газов, вызванный деятельностью человека в некоторой отрасли, рассчитывается исходя из объёма деятельности и установленных коэффициентов, чаще всего просто суммируются их произведения. Получаемая оценка имеет очень низкую точность, поэтому для итоговых результатов необходимо предоставлять информацию о степени их неопределённости.

Задача: необходимо оценить неопределённости расчётных объёмов выбросов, исходя из известных неопределённостей как коэффициентов, так и объёмов деятельности.

Применение стандартной теории погрешностей может привести к значительным ошибкам, т.к. неопределённости коэффициентов очень велики по сравнению с их значениями (100%-500%) и асимметричны. Поэтому для решения этой задачи были применены 3 метода:

  1. метод распространения ошибки (приближение распределения результата нормальным законом);
  2. метод Монте-Карло (приближение путём генерации случайных чисел);
  3. метод нечётких множеств (приближение распределения результата через функции принадлежности).

Каждый из методов обладает своими достоинствами и недостатками.

При расчётах методом распространения ошибки вычисляются математические ожидания и дисперсии [1] для всех элементарных операций (сложение, вычитание, умножение, деление, вычисление экспоненты). Эти расчёты являются точными. Далее, в предположении, что результат имеет нормальное распределение, вычисляется неопределённость.

Метод распространения ошибки является точным только в случае, если результат расчётов действительно распределён по нормальному закону. Этот метод менее точен в случае, если результат распределён по симметричному, но не нормальному закону. Для асимметричных распределений результата этот метод может привести к существенным ошибкам. Обратите внимание, что результат может быть асимметричным даже в случае симметричных распределений исходных данных.

Метод распространения ошибки очень быстрый, поэтому его рекомендуется применять для предварительной оценки неопределённостей.

При расчётах методом Монте-Карло для каждой исходной величины создаётся выборка случайных чисел. Для каждого набора случайных чисел вычисляется требуемое выражение, и в результате получается случайная выборка, по которой строится распределение статистическими методами. Поскольку не делается никаких априорных предположений о законе распределения результата, расчёты этим методом всегда корректны. Однако следует учитывать, что при расчётах используется датчик случайных чисел, поэтому для каждого запуска программы будет свой результат. Точность метода зависит от объёма выборки. С ростом объёма выборки растёт и время расчётов, поэтому данный метод рекомендуется для проверки результатов метода распространения ошибок.

Рассмотренные выше методы используются в предположении, что неопределённость исходных данных является случайной. Однако в математике имеются и другие модели неопределённостей, в частности, нечёткие множества или нечёткие числа. Элементарные операции (сложение, вычитание, умножение, деление, вычисление экспоненты и проч.) для нечётких чисел реализуются численными методами гораздо проще, чем для случайных величин. Поэтому в программе также реализован и метод нечётких множеств.

При расчётах эти методом исходные величины рассматриваются как нечёткие числа. Для сравнения с другими методами функция принадлежности результата преобразуется в плотность распределения, по которой и вычисляются неопределённости. Точность вычисления функций принадлежности определяется количеством точек.

Этот метод позволяет учесть асимметричность распределений, однако результаты могут существенно отличаться от метода Монте-Карло. При этом сложно сказать, какой метод точнее, поскольку в их основе лежат разные предположения о природе неопределённостей. В зависимости от того, какое предположение ближе к истине, такой метод и точнее. Однако, если оба метода дали близкие результаты, то это признак того, что расчёты верны, поскольку оценка мало зависит от предположений о природе неопределённости.

Программа реализована на VBA в виде макроса MS Excel. Пользователь может выбрать вид формулы и ввести данные в диалоговом окне.
